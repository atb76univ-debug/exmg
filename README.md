# Groove iPad Recorder — キャリブレーション付き版

HTTPSで公開し、iPad Safariの共有メニューから「ホーム画面に追加」して利用します。

## 機能

- 腕振りまたは自由身体運動を選び、低・中・高を各3つ、合計9刺激をランダム順に実行
- 「9試行を開始」を押してから1試行目の録画が始まるまで、任意の秒数（既定60秒）だけ待機時間を設ける。この待機時間は試行間休憩と同様に設定画面で変更可能
- 録画開始と同時に「ピッ」という合図音を鳴らし、参加者に録画開始を知らせる（1試行目以降も毎試行の録画開始時に鳴る）
- 録画開始後は音源を再生し、音源終了で録画停止・保存（2試行目以降は待機時間なし、試行間休憩の秒数だけ空けて次の録画を開始）
- キャリブレーションは試行と別カテゴリー。録画開始・合図音の直後（待機時間なし）に4拍×8小節（32拍）のメトロノームを再生
- 背面カメラ映像とマイク音声を保存
- 被験者別に動画と`metadata.csv`をZIPで一括保存

通常試行の動画ファイル名は `a101_腕振り_high1_2026-08-26T20-42-22Z.mp4` の形式です。キャリブレーションは `a101_calibration_日時.mp4` です。

ZIPを共有シートで「ファイルに保存」→「iCloud Drive」へ保存すればクラウド同期できます。実験前に、実機でカメラ・マイク権限、メトロノーム、音源、動画保存、ZIP解凍を確認してください。
