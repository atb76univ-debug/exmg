# Groove iPad Recorder — 1課題・9試行版

Xcode不要のiPad Webアプリです。HTTPSで公開し、Safariの共有メニューから「ホーム画面に追加」して使います。

## 実験仕様

- 実行する課題を「腕振り」または「自由身体運動」から1つ選択
- 低・中・高の異なる3音源ずつ、計9音源をランダムに各1回提示
- 録画開始 → 映像200フレーム後に音源再生 → 音源終了で録画停止・保存 → 休憩 → 次試行
- 背面カメラ映像とiPadマイク音声を録画
- カメラが止まった場合は20秒で録画を中止し、音源未再生のまま録画が続く状態を防止

## 音源選択

音源をiPadの「ファイル」アプリの「このiPad内」またはiCloud Driveに置きます。各欄の「ファイルを選択」から選びます。Apple Musicアプリ内の保護付き曲はWebアプリから利用できません。MP3/M4A/WAVなどを使ってください。

## 保存・クラウド同期

試行データはiPad内のアーカイブに残ります。被験者IDを選んで、その被験者の動画9本と`metadata.csv`を1つのZIPで保存できます。共有シートで「ファイルに保存」→「iCloud Drive」を選ぶとクラウド同期されます。

CSVには提示順、課題、条件、刺激ファイル名、開始・終了時刻、動画ファイル名などが記録されます。アーカイブのメモ更新と不要な試行の削除も画面上で可能です。

## 実験前の確認

実機で、カメラ・マイク権限、音源再生、1試行の録画、被験者別ZIPのiCloud Drive保存を必ず確認してください。カメラとマイクはHTTPSのページでのみ利用できます。
