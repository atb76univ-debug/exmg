# Groove iPad Recorder

HTTPSで公開してiPad Safariから「ホーム画面に追加」して使う、Xcode不要の実験アプリです。

## 実験仕様

- 腕振り・自由身体運動の2ブロック、計18試行
- 各ブロックでは、低・中・高の異なる3音源ずつ、計9音源をランダムに各1回提示
- 録画開始から200フレーム後に音源再生
- 音源終了で録画停止・保存。試行間休憩後は自動遷移し、ブロック間だけ手動遷移
- 録画にはiPadの背面カメラ映像とマイク音声を含む

## 保存と同期

動画とメタデータはiPad内のアーカイブへ保存されます。全試行をZIP（動画＋`metadata.csv`）で一括保存できます。共有シートで「ファイルに保存」→「iCloud Drive」を選ぶとクラウド同期できます。

CSVには全体の提示順（`presentation_order`）とブロック内の提示順（`block_trial_order`）を含みます。アーカイブのメモ更新と試行削除も画面上で行えます。

## 注意

音源はiPadの「ファイル」アプリ内に置いたMP3、M4A、WAV等を選んでください。Apple Musicの保護付き音源はWebアプリから選択できません。実験前に、カメラ・マイク権限、1試行の録画、音源再生、ZIPのiCloud Drive保存を実機で確認してください。
