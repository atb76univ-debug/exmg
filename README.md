# Groove iPad Recorder — キャリブレーション付き 1課題・9試行版

Xcode不要のiPad Webアプリです。HTTPSで公開し、iPad Safariの共有メニューから「ホーム画面に追加」して使います。

## 実験フロー

1. 実験者ID・参加者IDを入力し、実行課題（腕振りまたは自由身体運動）を選択します。
2. 低・中・高を各3つ、計9音源を選択し、試行順を作成します。
3. カメラ・マイクを開始します。
4. 必要に応じて「キャリブレーションを開始」を押します。録画開始後200フレームでメトロノーム（4拍×8小節、32拍）が始まり、終了時に録画停止・保存されます。
5. 「9試行を開始」を押すと、選択課題の9音源がランダム順で自動進行します。

## 保存データ

キャリブレーションは`category=calibration`、通常試行は`category=trial`として被験者ごとのアーカイブへ保存されます。どちらもiPadのカメラ映像とマイク音声を含みます。

被験者を選択して一括保存すると、キャリブレーション動画、通常試行動画、`metadata.csv`を1つのZIPとして保存できます。共有シートで「ファイルに保存」→「iCloud Drive」を選ぶとクラウド同期できます。

## 注意

音源はiPadの「ファイル」アプリに置いたMP3、M4A、WAVなどを選んでください。Apple Musicアプリ内の保護付き曲は利用できません。実験前に、カメラ・マイク権限、メトロノーム、音源、1試行録画、ZIP保存を実機で確認してください。
